# Technical Documentation, ADRs, and Runbooks

## Minimum docs for durable systems

- README with local run instructions.
- Architecture overview and dependency direction.
- ADRs for major decisions.
- API/event contract docs.
- Operational runbook for deploy, rollback, incidents, and dashboards.
- Security notes for secrets, auth, PII, and audit.

## ADR format

Use ADRs when a decision changes architecture, data model, operations, security posture, or team workflow.

Include: context, decision, alternatives considered, consequences, validation, owner/date.
