# Changelog

## [0.1.0] - 2026-10-23

Initial portable Agent Skills release of Software Improvement Loop.

- Four bounded improvement modes: performance, feature, test hardening, simplification.
- Frozen evaluation criteria, finite iterations, isolated work and evidence-based keep/revert policy.
- Independent correctness gates, noise-aware numeric comparison helper, no-test-weakening rule.
- Optional multi-agent workflow compatible with agent-host applications such as PandaCode.
- Standard-library-only comparator with regression tests and activation scenario fixtures.

This is the first tracked version. Runtime behavior in PandaCode and other client surfaces is not certified by the package's structural validation alone.
