# Changelog

## [0.1.0] - 2026-10-14

Initial research-grounded, portable Premortem Analysis skill release.

- Adds quick, standard and governed prospective failure analysis with clear adjacent-skill boundaries.
- Builds causal, evidence-graded, bias-aware risks with controllability, prevention, detection, response, validation and owner-held plan dispositions.
- Preserves uncertainty and explicit authorization limits; never equates imagined explanations with observed incidents.
- Adds JSON output contract, dependency-free validation, source-to-requirement traceability, activation/behavior scenario corpus, offline tests and deterministic packaging.
- Keeps the first 100 physical lines decision-complete and branch references directly discoverable.

Compatibility: Agent Skills portable core; host/distribution/runtime execution has not been independently verified.
