# Upstream provenance

This skill consolidates and adapts the workflow from the user-supplied `Deep-Research-skills-master.zip`, originally organized as separate Claude/OpenCode/Codex skills plus a web-search agent and source modules.

Preserved concepts include the two-phase outline/deep-research workflow, item/field refinement, resumability, batch controls, uncertainty markers, strict field-coverage validation, dynamic Markdown reporting, and source-specific search modules.

The adaptation removes host-specific install paths and mandatory private agent APIs, consolidates duplicated language/host variants into one portable skill, keeps output language configurable, embeds deterministic validators/report generation, and preserves the upstream MIT license in `LICENSE`.
