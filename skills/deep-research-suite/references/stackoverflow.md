# Community troubleshooting sources

## When to load

Use Stack Overflow / Stack Exchange / community forums when official documentation and source history leave version-specific questions unresolved.

## Procedure

1. Search exact error text, package/runtime version, configuration and platform qualifiers.
2. Prefer answers with reproducible minimal examples, confirmed supported versions and correction history; examine accepted-answer age and comments.
3. Confirm a claimed fix or workaround against official docs/source/tests where possible. Votes/acceptance signal usefulness, not correctness.
4. Separate workaround, root cause and permanent fix. Record limitations, permission risks, deprecated APIs and user-facing regression possibility.
5. Cite the exact thread/answer and date for derived claims. Do not execute arbitrary shell scripts copied from comments.
