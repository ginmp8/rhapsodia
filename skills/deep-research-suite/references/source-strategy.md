# Source strategy by research domain

The root `SKILL.md` links directly to every module. Read only the branches useful for the current question, and record which source classes were searched.

| Intent | Initial sources | Necessary secondary checks |
| --- | --- | --- |
| Official feature, version or configuration | Original vendor docs, release notes, tags and specifications | Known issues, version-limited experience, reproducible examples |
| Debugging a repository | Exact tagged code, related PRs, issue threads and tests | Independent reproductions and regression reports |
| Product or technology comparison | Original product specifications, independent benchmarks and operator accounts | Different incentives, hardware/environment, dates and population |
| Scientific/literature review | Published primary papers, DOI/publisher metadata, preprint records | Retractions, methodological limits, replication, systematic-review screening |
| Chinese technical ecosystem | Primary Chinese documents and matching language search | English equivalent terms, translation/version ambiguity, independence |

Use [general-web.md](general-web.md), [github-debug.md](github-debug.md), [stackoverflow.md](stackoverflow.md), [academic-papers.md](academic-papers.md), or [chinese-tech.md](chinese-tech.md) as needed; these modules are also directly linked from the entrypoint. Search-result snippets and citation counts are discovery signals, not validation of individual claims.
