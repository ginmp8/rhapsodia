# Chinese technical ecosystem

## When to load

Use when Chinese-language libraries, documentation or production experience may contain material evidence not represented in English sources.

## Procedure

1. Search both original Chinese names/terms and precise English equivalents; record language and translation/version ambiguity.
2. Prefer first-party Chinese documentation, official repositories and changelogs; use Juejin, SegmentFault, CSDN, Zhihu, CNBlogs, OSChina, V2EX and cloud engineering blogs for corroborating experiences.
3. Check whether posts are mirrors of the same vendor announcement or independent field reports; don't count mirrors as corroboration.
4. Verify commands, API names, version numbers and semantics in the original language rather than relying solely on automated translation.
5. Include translated interpretation and an original-language locator for consequential claims. Label uncertain translation rather than forcing equivalence.
