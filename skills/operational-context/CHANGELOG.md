# Changelog

## [1.1.0] - 2026-10-18

- Added caller-side, provenance-preserving long/multi-file evidence selection and coverage checks, including semantically indirect and middle-position evidence; no CLI or JSON contract changes.
- Added conditional position-sensitive evaluation criteria; no claim of measured model improvement.
- Normalized the optional OpenAI adapter to supported `CHAT`/`CODEX` product identifiers and fixed release-heading validity for this newly versioned release.

**Compatibility:** Existing commands, schemas, cache contents and RhapsodIA owner boundaries remain unchanged. No automatic content extraction or new tool privileges. Full host runtime behavior remains unverified.

**Validation:** See the separately generated current-run receipts; historical baseline checks cannot establish long-context model outcomes.

## 1.0.1 - 2026-10-16

Same-release clarification in RhapsodIA 0.11.0: Clarify temporary context packs versus persistent learning and runtime reuse; retain required source coverage and independent proof instead of optimizing only prompt size.

Respect enclosing mandatory graph-first agent policy while retaining optional graph selection for standalone context-pack workflows.

## 1.0.0 - RhapsodIA 0.8.0

Initial portable operational-context package: reference-first task packs, stable-prefix
composition, bounded output cards, artifact/evidence references, conservative deterministic
action lookup, content-free usage events and paired comparisons, bounded delegation and
retrieval advice, explicit quarantined pointer exchange, cooperative leases and GraphPatch.
No canonical workflow ownership, command execution, network, provider SDK or output restore.
