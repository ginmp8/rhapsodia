# Changelog

## [0.1.0] - 2026-11-08

### Added
- Portable source-to-destination Git tree integration planning using unique common ancestors and exhaustive tracked-path inventories.
- Audited conflict-resolution manifests with temporary Git indexes and explicit semantic review gates.
- Stale-plan detection, single-parent local commit creation, compare-and-swap branch update, no-force publication guidance and source/destination regression tests.

### Limitations
- No implicit fetch, remote push, full functional-parity claim or automated arbitrary-code conflict solver; live project tests and CI are separate acceptance requirements.
