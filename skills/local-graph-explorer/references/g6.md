# AntV G6 integration

## At a Glance
- **Purpose:** Pin the preferred graph renderer and isolate version-sensitive API assumptions.
- **Load when:** Changing G6 config, layouts, events, behaviors, CDN/vendor strategy, or upgrading G6.
- **Decision impact:** Requires version verification instead of copying stale v4/v5 advice and keeps the fallback path independent.

## Pinned baseline
The skill targets `@antv/g6` **5.1.1**. The generated CDN URL is version-pinned. A local reviewed `g6.min.js` may be provided with `--g6-js` and is inlined into the output for offline use.

Use the v5 global bundle as `const { Graph } = G6; new Graph({...}); graph.render()`. Behaviors are a flat array such as `drag-canvas`, `zoom-canvas`, `drag-element`. Event strings such as `node:click` are supported by the v5 event API.

## Version caveat
Do not copy old skill snippets blindly. Prior reference material incorrectly claimed that force `nodeStrength` could not be negative and that `preventOverlap` was unsupported; official 5.1.1 documentation differs. Recheck official docs before changing version-sensitive force/layout options.

The explorer intentionally uses minimal layout parameters and keeps force opt-in. Upgrading G6 requires rerunning package tests plus actual browser interaction checks.
