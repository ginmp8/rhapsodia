# Request Patterns

## Activate

- Build a Streamlit dashboard for onboarding metrics.
- Review this Streamlit app for caching and session-state problems.
- Add file upload and validation to my Streamlit app.
- Convert this notebook into a multipage Streamlit app.
- Add a chat interface with streaming model output.
- Prepare this Streamlit app for Docker deployment.

## Do not activate

- Write a generic Pandas analysis script with no app UI.
- Build a React frontend for a FastAPI service.
- Create a Dash app without Streamlit.
- Tune a database query when no Streamlit behavior is involved.

## Ambiguous

- Create a dashboard: ask or infer whether the target framework is Streamlit.
- Add authentication: clarify the deployment target and identity provider.
- Make it production ready: require auth, data sensitivity, deployment, and validation context before making strong claims.
