# Changelog

## [0.1.0] - 2026-11-07

First-tracked, documentation-only portable adaptation of the internally scoped Archify Tuning skill in `ginmp8/archify` at commit `a4065941f12be7967436261d9934784e381d423c`. Preserves the source/quality/elapsed-time experiment contract, frozen comparisons, trace export shape, and explicit uncertainty and authorization boundaries. Uses pinned upstream references and requires an actual compatible checkout for the original optional `round`, `collect`, `replay`, and `shots` scripts; those scripts and any private agent history are not bundled. This package does not claim to be the project's officially published maintainer skill.
