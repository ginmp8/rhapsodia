Optional runtime libraries retain their own licenses: NetworkX (BSD-3-Clause), openpyxl (MIT), PyYAML (MIT), pypdf (BSD-3-Clause), G6 (MIT), Tree-sitter (MIT), Roslyn (MIT), faster-whisper (MIT). Grammar packs, dependencies, codec libraries and model weights may have additional terms; inspect the exact selected distribution before redistribution. Python and SQLite are supplied by the chosen runtime, not vendored here.

Playwright is an optional test dependency, not required by generated artifacts. No assertion is made that every optional dependency version is currently free of vulnerabilities or license complications. Install only reviewed versions when a requested capability needs them and preserve their notices in a distribution that vendors them.
