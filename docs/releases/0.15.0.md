# RhapsodIA 0.15.0 — Archify visualization, review and tuning

## Overview

RhapsodIA 0.15.0 adds **three independently versioned Agent Skills**, moving the catalog from **59 to 62 Skills**, while retaining all **eight native agent profiles**. These additions broaden optional visualization, PR-review and experiment capabilities without changing existing roles, agent governance, required sessions or internal semantic contract versions.

## New Skills

### Archify 3.2.0 (`skills/archify/`)

- Native interactive HTML diagrams for **architecture, workflow, sequence, dataflow, lifecycle, ERD, class, tree, timeline, and waterfall**.
- **Explainer** mode for shareable one-page explanations with structured panels, charts, sources and embedded diagrams.
- Bundles upstream-derived CLI, renderers, Viewer, example files, schemas and delivery-validation paths. Its `finalize` command handles validation and delivery; browser quality gates still need a suitable browser.
- Uses a ChatGPT-compatible discovery description and selective reference previews. Node.js and any required browser are runtime dependencies of diagram generation, not of RhapsodIA's other Skills.

### Archify Review 0.1.0 (`skills/archify-review/`)

- Maintains the **Value / Cost / Impact** rubric for source-backed PRs and issues.
- Requires actual base/head identification, scoped review readiness, proportional test evidence and supported compatibility claims.
- A review verdict does not itself authorize approval, merge or publication.

### Archify Tuning 0.1.0 (`skills/archify-tuning/`)

- Framework for bounded before/after visual and semantic experiments using frozen inputs and attributable trace evidence.
- Distinguishes rendering checks from perceived quality, complete elapsed time and valid final delivery.
- **Methodology-only as packaged:** optional `round`, `collect`, `replay` and `shots` scripts are not bundled; they require a separate compatible Archify checkout.

## Compatibility, prerequisites and limitations

- **Additive update:** no migrations or changed credentials/permissions are required for existing RhapsodIA Skills or agents.
- **Authoring:** interactive diagrams require the bundled Archify runtime with a supported Node.js version. Browser-based checks require Chrome/Chromium or equivalent when used.
- **Tuning:** the optional repository experiment scripts are external and not silently downloaded or executed.
- **Validation boundary:** static package/manifest checks and CLI smoke tests cannot establish visual quality, full cross-host rendering, runtime permissions, or successful installation into a particular host.
- **Rollback:** select the previous immutable RhapsodIA v0.14.1 tag or distribution package. Independently installed Skills may need host-specific removal.
