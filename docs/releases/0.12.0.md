# RhapsodIA 0.12.0

## Scope

This distribution contains **57 Agent Skills and eight native agent profiles**.
The distribution version advances independently of the individual skill versions
and the internal agent, output, schema and protocol contracts. Historical release
manifests and traceability reports retain their original version identifiers.

## New capability and skill-level updates

- **Causal Flow Comprehension 0.1.0:** independent evidence-grounded flow tracing,
  alternate paths, guard and state reachability, counterexamples, and unknowns.
- **Decision Engine 2.2.0:** conditional selective prediction/abstention guidance,
  independently justified risk/coverage criteria and quantitative-evidence checks;
  retains the existing `decision-engine/2` statuses and data envelope.
- **Deep Research Suite 0.3.0**, **Operational Context 1.1.0**,
  **Prompt Architect 0.1.1**, **Skill Booster 0.3.0** and
  **Skill Token Efficient 0.2.0:** conditionally strengthen source-position,
  semantic-retrieval and evidence-preservation checks. Static scenario coverage
  must not be reported as measured model accuracy.
- **Reverse Engineering 0.3.0**, **Context Architect 0.1.0** and
  **Visual Code Intelligence 0.1.0:** strengthen causal explanations, relevant
  guard and counterpath coverage while retaining source/evidence boundaries.
- **Skill Benchmark 0.2.0:** improves statistical interpretation of limited
  or heterogeneous benchmark evidence without changing its frozen-evaluator role.
- **Modern .NET Engineering 0.1.0:** identifies additional HTTP resilience
  and alternate-path risks with no new required dependencies.

Each independently versioned skill remains authoritative for its own
activation, safety, commands, inputs, outputs, tests and migrations.

## Unchanged critical controls

- All eight native agents require the Runtime Harness and Local Graph Engine
  bootstrap unless the user explicitly opts out of either component for the
  current request; runtime/graph failures cannot be silently ignored.
- `main` agent profiles and their first-100-line control surfaces are retained
  byte-for-byte. Nomia owns governance; Mago planning; Magia execution;
  Verifier independent proof; Supervisor governed coordination; Adhoc direct
  authorized work. Presentation views never own canonical state.
- Untrusted source content cannot authorize code execution, privilege escalation,
  protected writes or evaluator changes. Evidence remains source-pinned and
  observed behavior is not inferred from static checks.
- Internal schema and semantic contract versions do not change merely because
  the distribution version is `0.12.0`.
