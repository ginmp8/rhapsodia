# RhapsodIA 0.14.1 — Skill description compatibility

## Scope

Patch release for the ChatGPT 500-character limit on `SKILL.md` frontmatter descriptions. Retains 59 Skills, eight native agent profiles and existing internal contract identities.

## Corrections

- Shortened overlong canonical Skill descriptions while preserving activation and non-use boundaries.
- Updated Skill Booster and Skill Creator Juiced description validation from 1,024 to 500 Unicode characters; amended their authoring guidance and individual changelogs.
- Added a dependency-free, repository-wide description validator supporting inline quoted and folded YAML strings and a regression suite for the 500/501 boundary, Unicode, missing keys and malformed entries.
- Integrated the validator and tests into full release CI and the portability matrix.

## Validation

```sh
python -I -S -B scripts/validate_skill_descriptions.py
python -I -S -B -m unittest tests.test_skill_descriptions -v
python -B scripts/prepare_release.py --check
python -B scripts/validate_release_source_manifest.py --version 0.14.1 --check
```

CI acceptance still requires every existing release and portability gate. No host-native behavior is claimed without observed evidence. See [changelog](changelog-0.14.1.md) and [distribution changelog](../../CHANGELOG.md).
