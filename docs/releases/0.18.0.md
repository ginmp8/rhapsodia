# RhapsodIA 0.18.0 — Deterministic PR evidence and scoring

## Overview

This source-release candidate adds one original Agent Skill, increasing the canonical inventory from 76 to **77** while retaining eight native agent profiles. Package release metadata advances to **0.18.0**. The new Skill keeps an independent **0.1.0** package version and does not alter other Skills' semantic contract versions.

This document describes proposed source changes, not a published tag, a completed release or confirmed host installation.

## New capability: Deterministic PR Audit

- [Skill instructions](../../skills/deterministic-pr-audit/SKILL.md), [CLI guide](../../skills/deterministic-pr-audit/README.md), [scoring contract](../../skills/deterministic-pr-audit/references/scoring-contract.md)
- [Skill CLI](../../skills/deterministic-pr-audit/scripts/pr_audit.py) and [repository wrapper](../../scripts/deterministic_pr_audit.py)
- Capture GitHub PR metadata and issue comments with SHA-bound source identity, then extract explicit REQ/AC and acceptance checkboxes into reviewable criteria.
- Freeze a one-time verification plan; inspect local Git objects at the exact captured commit; optionally execute independently authorized tests in an isolated checkout.
- Compute verified completion from passing applicable requirements using fixed Decimal arithmetic, with separate PARTIAL, FAIL, UNVERIFIED and NOT_APPLICABLE states.
- Emit immutable JSON/Markdown evidence and compare only candidates sharing identical requirements, check-plan digest and algorithm version.

## Quick start

```bash
python scripts/deterministic_pr_audit.py --help
python -m unittest discover -s skills/deterministic-pr-audit/tests -v
```

GitHub capture requires `gh` with appropriate read permissions. The executable targets Python 3.10+ and the standard library. Static inspection additionally requires Git and a local repository containing the pinned commit.

## Reproducibility and limitations

Identical frozen `source.json`, `requirements.json`, `checks.json`, `evidence.json` and algorithm bytes yield identical report bytes. This is **not** a claim that arbitrary natural-language specs can be interpreted deterministically or that text checks alone establish functional correctness. The initial requirements inventory, check definitions and semantic adequacy of test assertions require independent review. Without proof, an item remains UNVERIFIED; changed evidence produces a new assessment.

The bundled suite contains **15 offline regression cases**. Their execution is separate from RhapsodIA's release CI and real GitHub/harness activation. No release tag or merge is performed by this change.
