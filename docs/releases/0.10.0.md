# RhapsodIA 0.10.0

Date: 2026-10-15. Source distribution only; no published tag, remote host session or deployment claimed. Previous source release: **0.9.0**.

## Scope

Seven existing canonical agent prompts gain sharper discovery metadata and conditional, non-authoritative decision/risk support. **No new agents, domain skills, mandatory services or runtimes.** The 56 bundled skills, their individual `VERSION` identities, ecosystem handoff v3 schema, `handoff/v1`, read-only Analyst/Supervisor boundaries, Verifier oracle, single-writer ownership, and current budgets remain unchanged.

## Changes

- `agents/*.agent.md`: shorter descriptions with explicit intent/non-intent, compressed runtime-context discipline and precise, task-dependent decision/risk routing.
- `bounded-decision-judgment` optionally discovers Decision Engine-like support for an actually bounded binary/choice/score question. Mechanical validators and domain owners retain precedence; semantic advice cannot approve production/business actions.
- `prospective-failure-review` optionally discovers Premortem Analysis-like support for a real future high-impact plan. Findings are explicitly hypothetical and require evidence, counterchecks, proposed mitigation and owner disposition. Existing incidents/debugging and trivial changes are excluded.
- `material-uncertainty-reflection` optionally discovers Discernment Nudge-like support for a complete, human-facing recommendation with a consequential unresolved hinge. Machine/handoff outputs, completed verification, and reflection-only agent calls are excluded.
- `docs/agents/ARCHITECTURE.md`: explain semantic IDs, which domain owns decisions, optional skill discovery, fail-closed required vs degraded optional resolution, and abstention.
- `tests/agent-scenarios.json`: planned positive, negative, ambiguous/failure routing cases; `scripts/validate_agents.py` and its unit tests guard semantic-lens presence.
- Regenerate canonical marketplace host projections, the Agent `MANIFEST.json` and deterministic full-repository source inventory. Align release CI pins to 0.10.0.

## Validation and limits

Validation must verify the exact candidate, generated manifest consistency, source hashes, local tests, archive reproducibility, and no new dependency or permission expansion. Existing historical 0.9.0 files are retained. Static scenario coverage does **not** establish native-host/model activation precision, runtime token cost or behavior equivalence. The token-efficiency proxy measures estimated instruction tokens only; actual provider usage requires controlled execution on selected hosts.

Measured with the package's `skills/skill-token-efficient/scripts/refactor_audit.py` `estimator-v1` tokenizer on the **same** seven complete `agents/*.agent.md` surfaces (including frontmatter): **11,275 -> 10,223 estimated units** (**-9.33%**). The Supervisor changed from **3,824 -> 3,015** (**-21.16%**). Exact baseline/candidate file hashes and counts are in [agent-token-estimate-0.10.0.json](agent-token-estimate-0.10.0.json). This is not actual GPT/Claude/Copilot/Cursor token consumption, activation recall or runtime-cost evidence.
