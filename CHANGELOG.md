# Changelog

## [0.16.0] - 2026-11-08

### Added
- Spec-to-Implementation Audit coordinator v0.3.0 with frozen normative-source and candidate identities, five-stage dispatch, requirement-to-proof traceability and scoped verdicts.
- Five v0.2.0 local audit adapters for source criteria, code reachability, causal counterpaths, falsifiable verification oracles and original/candidate regression parity.
- Standard-library routing and report/stage-receipt validators, original activation fixtures and regression tests, and provenance notes for each new Skill.

### Changed
- Distribution count from 62 to 68 Skills, retaining eight agent profiles and independently versioned internal semantic contracts.
- Marketplace/plugin manifests, release documentation, source inventory, package-version checks and cross-platform CI for 0.16.0.

### Compatibility
- Existing RhapsodIA specialists are composed rather than duplicated. `sdd-reviewer` and `code-review` are optional external skills; local adapters remain usable without them.
- Audit workflows remain read-only by default and make no claims of unexecuted tests, independent delegation or full compliance without grounded evidence.


## [0.15.0] - 2026-11-07

### Added
- Archify v3.2.0: upstream-derived diagram runtime with 10 native types, Explainer, deterministic CLI delivery, complete renderer/schema payload, license and source provenance.
- Archify Review v0.1.0: evidence-based Value/Cost/Impact evaluation with current-branch handling and contribution readiness policy.
- Archify Tuning v0.1.0: bounded, traceable visual-quality experiments; repository-only experiment scripts remain optional, not bundled.
- Versioned provenance, attribution and static integration regression checks for all three new packages.

### Changed
- Distribution and host marketplace metadata, release CI, source manifest and docs for 0.15.0, increasing the Skill inventory from 59 to 62 with eight agents unchanged.
- Cross-platform static validation and Linux Node.js CLI smoke checks for Archify, without claiming browser or host-activation parity.

### Compatibility and licensing
- Existing Skill packages, agent profiles and internal contracts are unchanged. New Archify packages preserve upstream Apache, historical MIT and pertinent third-party attributions. Commercial use of embedded marks remains subject to their own rights.


## [0.14.1] - 2026-10-26

### Fixed
- Shortened overlong discovery descriptions for ChatGPT compatibility without changing Skill responsibilities.
- Corrected the existing 1024-character validator allowances in Skill Booster and Skill Creator Juiced to a hard maximum of 500 Unicode characters.

### Added
- Catalog-wide frontmatter description validation and regression tests, enforced by release CI and the portable-host matrix.

### Changed
- Release metadata, README and distribution documentation for 0.14.1; maintained the 59-Skill and eight-agent inventory.


All notable changes to the RhapsodIA distribution are documented here. Individual Skills follow their own version histories and are not automatically bumped with the distribution.

## [0.14.0] - 2026-10-25

### Added
- Software Improvement Loop v0.1.0, packaged under `skills/software-improvement-loop/`, with four bounded improvement modes, frozen evaluation, isolation, regression gates, and limited iterations.
- A standard-library-only metrics comparator, unit tests, activation fixtures, and report templates.
- Pull-request-triggered full release checks and Skill tests in the Linux, Windows, and macOS portability matrix.

### Changed
- Advanced marketplace, host manifests, agent manifest, release workflows, version assertions, README, and source inventory to distribution version 0.14.0.
- Added Skill archive inventory checks while retaining independent Skill versions, internal semantic contracts, and eight native agent profiles.

### Validation
- Full release and cross-platform CI must pass before acceptance. Structural checks do not establish native-host activation or real software performance gains.
